公開済みアプリの更新方法
1. Supabaseで、現在のお小遣いアプリのプロジェクトを開く。
2. SQL Editor → New query に household_upgrade.sql の全文を貼り付け、Run。
   このSQLは既存のお小遣い記録を残して家計簿のテーブル・関数を追加します。
   再実行しても記録は削除されません。
3. GitHubの同じリポジトリで、次の5ファイルを上書きしてCommit changes。
   index.html
   styles.css
   app.js
   core.js
   manifest.json
4. config.js は今の接続設定のまま残してください。ZIP内の未設定版で上書きしない。
5. 公開の反映後、Safariでアプリを開き直す。最下部が v2.0 なら更新済み。
   URLは変わりません。
6. 一方の端末で家計を1件登録し、もう一方で「更新」を押して共有を確認。
   お小遣いの支出が家計簿にも1件だけ出ることを確認してください。

新しく設置する場合
1. Supabaseで supabase_setup.sql を全文実行（お小遣い+家計簿をまとめて作成）。
2. Authentication → Users で共有ログイン用ユーザーを1人作成。
3. config.js のSUPABASE_URL、SUPABASE_ANON_KEY、LOGIN_EMAILを設定。
4. HTML/JS/CSS、manifest.json、service-worker.js、iconsフォルダをGitHub Pagesで公開。
5. 二人の端末で同じメール・パスワードでログイン。
接続情報やパスワードはこのZIPに入っていません。
パスワードやservice_role/secret keyはソースに書かないでください。

家計とお小遣いの連携
・お小遣いの支出は、家計簿に「お小遣い」項目として自動表示。
・同じ記録を参照しているため、二重登録/二重計上はしません。
・家計簿からお小遣いの行の「編集」を押すと、お小遣いの編集欄に移動。
・修正・削除すると、お小遣い残高と家計簿の両方へ反映。
・毎月の各150ドルチャージは家計簿の収入/支出に含めません。
・追加チャージも家計簿の収入/支出に含めません。
・「支出の返金」をお小遣いに登録すると、残高が戻り、返金した月の家計支出から差し引きます。
・旧版の「返金・追加チャージ」は用途を判別できないため、残高を保ったまま「追加チャージ」と表示します。
  もし実際に買い物の返金だったものがあれば、種類を「支出の返金」に編集してください。
・家計から直接登録した支出はお小遣い残高を減らしません。
・Hayuは家計簿の対象です。Hayuへの自動お小遣いチャージはありません。

普段の使い方
「誰の分？」は、支払った人ではなくそのお金を使った対象を選びます。
例：Ritsuyaが払ったHayuの習い事 → Hayu / 教育・保育。
家族で食べる食料品 → 家族共通 / 食費。
項目追加は、入力欄の「＋ 項目を追加」から。支出/収入を選び名前を入力。
同じ種類・同じ名前の項目を再追加しても重複しません。
カテゴリーの削除はManage categoriesから可能です。改名は未搭載です。

予算
月の予算は、その月ごとに設定します。自動繰り越し・翌月コピーはしません。
お小遣いの実際の支出を含む、その月の総支出を予算と比較します。
「収支」は入力済み収入−入力済み支出。銀行口座の実残高ではありません。

お小遣いの継続仕様
・開始月2026年9月。一人毎月150ドル。
・未使用分は翌月へ繰り越し。マイナス残高も記録可能。
・開始月から当月までの月数×150＋返金/追加－支出で計算。
・米国東部時間 America/New_York の毎月1日が基準。
・開かなかった月も計算に含みます。定期実行の設定は不要です。
・お小遣いは2026年9月以降、家計簿は2000年1月以降の日付で入力可能。
・未来の日付には記録できません。

共有・保存
同じ共有アカウントで使います。別アカウントは別データになります。
各テーブルのRLSで、そのアカウントのデータだけ読み書きします。
表示中は20秒ごと、アプリへ戻ったときにも同期します。
同じ記録を同時に編集した場合はバージョンを照合し、上書きを防ぎます。
オフライン保存、銀行/カード明細の自動取得、レシート読取、固定費自動登録は未搭載。
通貨はUSD。実際の送金・銀行口座操作は行いません。

iPhoneで使う
Safariで開き、「共有」→「ホーム画面に追加」。
金額と日付は横並び。入力欄の文字は16px固定で自動ズームを抑制。
CSS/JSのURLにはバージョンを付けています。
既存ホーム画面アイコンの名前を新しい「家族のおさいふ」にしたい場合は再追加してください。

お試し画面
URLに ?demo=1 を付けると、接続設定なしで画面を試せます。
お試しデータは保存されず、再読み込みすると初期状態に戻ります。
